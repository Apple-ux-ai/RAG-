# 旅行管家 RAG 客服 API

> 面向旅行咨询场景的客服问答服务，结合本地 FAQ 知识库与通义千问，为客服系统和 IM 调用方提供多轮对话接口。

## 项目介绍

本项目将旅行知识检索、回复生成和对话状态处理封装为一组 FastAPI 接口。服务会参考旅行 FAQ、违禁词规则、客户对话历史及可选的商品信息，帮助客服回答行程与产品问题，并保持多轮对话中的目的地、出行需求和联系方式上下文。

系统也处理客户消息中的手机号和微信号、平台通知、广告与重复请求等情况，按业务规则决定是否生成或发送回复。价格、日期、人数等资料不足时，接口可结合已知上下文继续确认，避免把未知信息当成事实。

## 主要能力

- **FAQ 检索与回答**：从项目内的旅行 FAQ 中查找相关内容，并结合通义千问组织简洁回复。
- **多轮对话上下文**：根据调用方传入的历史和商品上下文，延续目的地、行程时长和客户需求。
- **客户消息处理**：识别联系方式、广告和平台通知，处理重复消息，并按实际留资状态控制回复话术。
- **IM 投递确认**：提供带鉴权的 IM 回复接口和发送确认接口，支持重试时复用待发送回复。
- **健康检查与限流**：提供服务状态查询，并对主要客服接口实施按 IP 限流。

## 技术与数据

- Python、FastAPI、Pydantic
- OpenAI Python SDK 接入 DashScope 通义千问
- 项目内文本知识库：`客服FAQ-度假旅行版.txt`、`违禁词.txt`
